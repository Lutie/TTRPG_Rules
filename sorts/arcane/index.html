    18 sorts pour Arcane

    Projectiles Magiques

    Difficulté : 16, Drain : 14, Type de sort : Pouvoir, Domaine du sort : ✡, École du sort : École de Destruction Mot de diffusion : Projectile : Portée : Portée magique x2, Vecteur : Vue. Mot de propagation : Unique : Touche une cible unique. Mot de structure : Pluie : Le sort s'applique au moment où il est lancé puis aux cinq rounds d'après, même cible, la cible doit être un lieu. Modificateurs de Magnitude : PWR -3/-3/-3/-3/-3/-3 (6) Mot de liaison : Long : La distance de diffusion du sort est doublée.

    Mot de pouvoir : Conjuration ✸ (Iungo (Joindre) / Keljung (Kel + jung)) : Produit un effet d'attaque physique (armure) infligeant [Magnitude x0.66] de dégats physique (PV) basés sur l'élément des arcanes. Clé : ✡️ Arcane: Keljungys

    Description : Bombarde une zone pendant plusieurs rounds avec une pluie de projectiles arcaniques meurtriers.

    Mot de pouvoir : Contradiction ⛊ (Contra (Contre) / Bricontra (Bri + contra)) : Contrecarre le sort ciblé dont le niveau est égal ou inférieur à [Magnitude/5], les ressources engagées sont perdues. Clé : ✡️ Arcane: Bricontrays

    Description : Interrompt et annule un sort en cours si son niveau n’est pas trop élevé.

    Mot de pouvoir : Restriction ⛊ (Stringo (ResseRer) / Basstrin (Bas + strin)) : Génère un effet qui génère une pénalité de [Magnitude/5] à toutes les actions d'un type (choisit au lancement du sort) qui vise la cible. Clé : ✡️ Arcane: Basstrinys

    Description : Impose une pénalité éphémère à un type d’action visant une cible, comme une “interdiction”.

    Dénis des Arcanes

    Difficulté : 14+X, Drain : 14+X, Type de sort : Interruption, Domaine du sort : ✡✡, École du sort : École d'Abjuration et École de Destruction Mot de diffusion : Manifestation : Portée : Portée magique x1, Vecteur : Vue, Cible soi possible. Mot de propagation : Unique : Touche une cible unique. Mot avancé : Annexe : Le sort est avancé (voir les règles), entre autre il requière une ACTS de plus pour être lancé, de plus le sort est associé à un second mot de pouvoir, cet effet subit PWR-2, le malus de PWR ne peux pas être supérieur à 4 une fois tous les mots associés.

    Mot de pouvoir principal : Contradiction ⛊ (Contra (Contre) / Bricontra (Bri + contra)) : Contrecarre le sort ciblé dont le niveau est égal ou inférieur à [Magnitude/5], les ressources engagées sont perdues. Clé : ✡️ Arcane: Bricontrays Mot de pouvoir secondaire : Distorsion ✸ (Torsio (Torsion) / Keltor (Kel + tor)) : Produit un effet d'attaque mentale (résolution) infligeant [Magnitude] de dégats arcanique (PM) basés sur l'élément [clé]. Clé : ✡️ Arcane: Keltorys

    Description : Contre un sort tout en infligeant une violente distorsion qui brûle la mana de l’adversaire.

    Notes : Distorion : Attaque vs MAG.

    Description : Dissipe brutalement une grande partie des barrières actives sur la cible.

Mot de propagation : Unique : Touche une cible unique. Mot de liaison : Boost : Lorsque le sort est lancé le personnage peux dépenser autant de mana que souhaité pour augmenter la puissance du sort d'autant, maximum 2 par dés.

    Description : Force un lanceur à “payer” en mana pour que son sort passe, sinon il est annulé.

    Mot de pouvoir : Translation ⧉ (Fero (Porter) / Enlata (En + lata)) : Déplace une cible inerte de [Magnitude] mètres, sur une cible non inerte le sort agit comme un déplacement forcé avec la moitié de la magnitude (vs robustesse), les distances de collision sont divisées par deux le cas échéant. Clé : ✡️ Arcane: Enlatays

    Description : Déplace par télékinésie un objet ou une créature, comme une poussée invisible.

Mot de propagation : Unique : Touche une cible unique. Mot de liaison : Long : La distance de diffusion du sort est doublée.

    Mot de pouvoir : Extraction ⛊ (Extraho (Tirer hors de) / Barextra (Bar + extra)) : Génère un effet qui téléporte (sans collisions donc) la cible d'un point A à B distant d'au mieux [Magnitude/4] de distance, ce sort ne peux affecter que soi ou un allié, le lanceur de sort doit pouvoir être mesure de voir le point d'arrivé et être la cible ou de voir la cible. Clé : ✡️ Arcane: Barextrays

    Description : Téléporte soi ou un allié vers un point visible, sans collision, pour se repositionner instantanément.
