    Sorts – Divination

    10 sorts pour Divination

    Vision du Passé

    Difficulté : 10, Drain : 10, Type de sort : Pouvoir, Domaine du sort : 👁, École du sort : École de Divination Mot de diffusion : Contact : Portée : Mêlée, Vecteur : Touché, Cible soi possible. Mot de propagation : Unique : Touche une cible unique.

    Mot de pouvoir : Rétrocognition ⊙ (Retro (Arrière) + Nosco (Connaître) / Diretro (Di + retro)) : Génère un effet permettant au lanceur de sort de consulter le passé de la cible, jusqu'à [Magnitude]² minutes dans le passé, la vision en question n'est pas lié aux sens de la cible mais en est totalement indépendant. Clé : 👁️ Vision: Diretroeth

    Vision du Futur

    Difficulté : 10, Drain : 10, Type de sort : Pouvoir, Domaine du sort : 👁, École du sort : École de Divination Mot de diffusion : Contact : Portée : Mêlée, Vecteur : Touché, Cible soi possible. Mot de propagation : Unique : Touche une cible unique.

    Mot de pouvoir : Précognition ⊙ (Prae (Avant) + Nosco (Connaître) / Dornosc (Dor + nosc)) : Génère un effet permettant au lanceur de sort de consulter le futur de la cible, jusqu'à [Magnitude]² minutes dans l'avenir, cette vision ne se fait pas pars le prisme des sens ou de la perception de la cible mais d'une façon plus extérieur et neutre, ce futur peux changer si quelque chose le préviens mais la nature du monde cherchera à contourner tout changement trop important, le changement doit donc être drastique pour forcer la main du destin. Clé : 👁️ Vision: Dornosceth

    Exploration Mémorielle

    Difficulté : 12, Drain : 12, Type de sort : Pouvoir, Domaine du sort : 📚, École du sort : École de Divination Mot de diffusion : Manifestation : Portée : Portée magique x1, Vecteur : Vue, Cible soi possible. Mot de propagation : Unique : Touche une cible unique.

    Mot de pouvoir : Rétrospection ⊙ (Specio (Regarder) / Dispecio (Di + specio)) : Génère un effet qui permet au lanceur de sort d'avoir la mémoire de la cible (objet ou personne ou lieu), la mémoire étant la liste factuel des interactions et événements vécus par la cible, les informations étant celles dont la cible est dotée (par example si elle ne connait pas le nom d'une cible alors ce dernier n'est pas obtenu via l'effet du sort), si un événement est survenu mais de nature inconnue la cible n'a pas plus d'informations à donner à ce sujet, pas plus qu'elle ne peux renseigner sur les événements qui sont survenus et dont elle n'a pas connaissance (et ce même si elle en a été la cible directe), l'effet peux remonter jusqu'à [Magnitude²] minutes dans le temps. Clé : 📚 Savoir: Dispecioaum

    Oeil de Scrutation

    Difficulté : 14, Drain : 12, Type de sort : Pouvoir, Domaine du sort : 👁, École du sort : École de Divination Mot de diffusion : Nom : Portée : Lieu, Vecteur : Voix. Mot de propagation : Unique : Touche une cible unique.

    Mot de pouvoir : Inspection ⊙ (??? / ???) : Le sort permet au lanceur de sort de « percevoir » les environs d’un lieu, d’un objet ou d’une personne donnée. La cible doit être désignée en fonction d’un élément, d’une matière, de corps, d’esprits, d’un objet, etc... Qui le caractérise ou le représente. La distance maximale de scrutation est fixée à [Magnitude²] mètres. Le lanceur de sort ne sait pas forcément d'où est-ce qu'il scrute, mais peux essayer de le déduire en observant bien la scène. Clé : 👁️ Vision: Dorquereth

    Chemin de la Destiné

    Difficulté : 8, Drain : 8, Type de sort : Pouvoir (Percevoir), Domaine du sort : 👁, École du sort : École de Divination Mot de diffusion : Soi : Portée : Sans, Vecteur : Sans, Cible soi possible. Mot de propagation : Unique : Touche une cible unique.

    Mot de pouvoir : Destination ⊙ (Sto (Se tenir) / Delstatio (Del + statio)) : Génère un effet qui permet à la cible de « percevoir » l’itinéraire vers un lieu ou un objectif précis ; la vision du chemin peut se décliner selon [Magnitude/10] critères différents (le plus court, le plus sûr, le plus fréquenté, le plus discret, etc.), au choix du lanceur au moment de l’activation, et celui-ci reçoit alors une perception nette de la direction à prendre, des étapes à franchir et des dangers potentiels, comme si le tracé était projeté dans son esprit, la distance maximale couvert par ces indications est de [10 x Magnitude²] mètres. Clé : 👁️ Vision: Delstatioeth

    Retrouver une Personne

    Difficulté : 8, Drain : 8, Type de sort : Pouvoir, Domaine du sort : 👁, École du sort : École de Divination Mot de diffusion : Soi : Portée : Sans, Vecteur : Sans, Cible soi possible. Mot de propagation : Unique : Touche une cible unique.

    Mot de pouvoir : Traçation ⊙ (Traho (Tirer, tracer) / Deltrac (Del + trac)) : Le sort permet au lanceur de sort de connaitre la localisation d'une personne connue. La localisation apparait dans l'esprit du lanceur de sort. Il peux reconnaitre ou pas les lieux, ce n'est pas automatique. La cible doit être connue et le lanceur de sort doit l'avoir cotoyer un minimum. La distance maximale de localisation est fixée à [20 x Magnitude²] mètres. Clé : 👁️ Vision: Deltraceth

    Plan Magique

    Difficulté : 8, Drain : 8, Type de sort : Pouvoir, Domaine du sort : 📚, École du sort : École de Divination Mot de diffusion : Soi : Portée : Sans, Vecteur : Sans, Cible soi possible. Mot de propagation : Unique : Touche une cible unique.

    Mot de pouvoir : Cartographie ⊙ (Charto (Carte) / Dichart (Di + chart)) : Génère un effet permettant au lanceur de cartographier mentalement une zone jusqu’à [Magnitude²] m de rayon, révélant le plan des lieux, issues, pièces et voies praticables ; les éléments mobiles n’apparaissent pas, mais les obstacles et points d’étranglement sont identifiés, la précision des détails dépendant de ce que sait le lanceur de sort, et donc du résultat de ses recheches préalables. Clé : 📚 Savoir: Dichartaum

    Analyse des Attributs

    Difficulté : 8, Drain : 8, Type de sort : Pouvoir (Infos), Domaine du sort : 📚, École du sort : École de Divination Mot de diffusion : Soi : Portée : Sans, Vecteur : Sans, Cible soi possible. Mot de propagation : Unique : Touche une cible unique.

    Mot de pouvoir : Profilation ⊙ (Fila (Fil) / Delfila (Del + fila)) : Génère un effet qui permet au lanceur de sort de percevoir des attributs d'une cible, le personnage peux ainsi recevoir [Magnitude/4] informations de la sorte, ces informations sont relativement floues (assez faible, assez élevées, plus bas que toi, plus haut que toi), le personnage peux à la placer percevoir [Magnitude/6] informations avec précision (chiffrée), un test de sauvegarde réussie permet (en plus de réduire la magnitude) de priver le lanceur de sort de la possibilité d'avoir des détails. Clé : 📚 Savoir: Delfilaaum

    Plonger dans la Mémoire

    Difficulté : 12, Drain : 12, Type de sort : Pouvoir, Domaine du sort : 📚, École du sort : École de Divination Mot de diffusion : Manifestation : Portée : Portée magique x1, Vecteur : Vue, Cible soi possible. Mot de propagation : Unique : Touche une cible unique.

    Mot de pouvoir : Mnémonisation ⊙ (Mnesis (Mémoire, grec) / Dormnesi (Dor + mnesi)) : Génère un effet qui permet à la cible de réaliser un test de mémoire afin de se souvenir d'un détails précis, le test se fait avec un bonus de [Magnitude/3], l'effet garantis de pouvoir retrouver des souvenirs normalement très difficile d'accés mais cette particularité est à la discrétion du MJ (et certains souvenir peuvent rester fermés quoi qu'il arrive, auquel cas le personnage saura qu'il y a une raison à ça). Clé : 📚 Savoir: Dormnesiaum

    Vision du Danger

    Difficulté : 8, Drain : 8, Type de sort : Pouvoir (Senseur), Domaine du sort : 🛡, École du sort : École de Divination Mot de diffusion : Soi : Portée : Sans, Vecteur : Sans, Cible soi possible. Mot de propagation : Unique : Touche une cible unique.

    Mot de pouvoir : Intuition ⊙ (Tueor (Regarder) / Deltueo (Del + tueo)) : Génère un effet de perception du danger (voir règle sur les "senseurs"), révèle ainsi les êtres qui souhaite ou pourrait s'en prendre au personnage, quel qu'en soit la raison... Cette effet est éphémère et le lanceur de sort ne peux observer attentivement qu'une partie des éléments ainsi repérés, soit [Magnitude/5]. Clé : 🛡️ Guerre: Deltueoorr
